# Variant Association with Psychopathy – Machine Learning Analysis

## 📌 Project Overview

This project explores the association between clinical/genomic variables and psychopathy-related outcomes using machine learning methods. The goal is to identify important predictive features and evaluate model performance for classification tasks in a healthcare context.

The analysis includes data preprocessing, feature engineering, feature selection, and multiple machine learning models.

---

## 🧠 Objectives

* Analyze clinical and biological variables linked to psychopathy-related outcomes
* Perform feature selection to identify the most informative predictors
* Train and evaluate machine learning models for prediction tasks
* Optimize model performance using hyperparameter tuning techniques
* Compare model performance using standard evaluation metrics

---

## 📂 Repository Contents

This repository includes:

* `Genomic All variables NEW.ipynb` → Main analysis notebook

* Cleaned clinical datasets
* CSV/XLSX files used for training and evaluation
